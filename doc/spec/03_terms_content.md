# 仕様書 3: 最初の5語の中身

> `TermSeeder` に写す文章。仕様書 2 の `terms`・`quiz_questions`・`quiz_choices` の項目に合わせている。  
> **たたき台**なので、運営者（自分）の言葉に書き直してから使う。仕様書 1 の「コンテンツの方針」に従う。

<br>

## 書き方のルール

- `summary`（ひとこと）：一覧に出す。30文字くらいまで
- `explanation`（やさしい説明）：3行くらいまで
- `analogy`（身近なたとえ）：日常の場面で
- `points`（ポイント）：3つまで、1つ1行
- クイズは選択肢3つ。「正解」「不正解」は書かない。どの選択肢にも、その考え方へのひとこと（`feedback`）を書く
- 数字の例を出すときは「計算の例」と書き、増えることを約束しない

<br>

## 1. 投資（slug: `investment`）

- **ひとこと**：お金に働いてもらうこと
- **やさしい説明**：使う予定のないお金を、成長しそうな会社などに託して、時間をかけて増えることを期待することです。預金と違って、増えることもあれば、減ることもあります。
- **身近なたとえ**：庭に種をまくようなもの。すぐには実りませんが、時間をかけて育てると、実がなることを期待できます。ただ、天気によっては育たない年もあります。
- **ポイント**
  - 投資は「増えるかもしれないし、減るかもしれない」もの
  - 預金は、元本（預けたお金）が守られている
  - 使う予定のないお金で始める

### クイズ

**問題**：投資と預金のちがいとして、あてはまるのはどれでしょう？

| 選択肢 | 考え方のポイント（feedback） |
|-|-|
| 投資は、預けたお金が必ず増える | 投資には「必ず」はありません。増えることもあれば、減ることもあるのが投資です。 |
| 投資は、増えることも減ることもある | ここが預金との大きなちがいです。だからこそ、使う予定のないお金で始めることが大切です。 |
| 投資も預金も、しくみは同じ | 預金は元本が守られていますが、投資は守られていません。ここが大きなちがいです。 |

<br>

## 2. 複利（slug: `compound-interest`）

- **ひとこと**：増えた分も、また増えていくしくみ
- **やさしい説明**：増えたお金を引き出さずにそのままにしておくと、次はその増えた分にも利益がつきます。これをくり返すことで、時間がたつほど増え方が大きくなります。
- **身近なたとえ**：雪だるまづくり。小さな雪玉も、転がすうちに雪がくっついて、どんどん大きくなります。
- **ポイント**
  - 増えた分も、元のお金といっしょに増えていく
  - 時間が長いほど、効果が大きくなる
  - 計算の例：100万円が毎年3%増えると、10年で約134万円（実際は増えたり減ったりします）

### クイズ

**問題**：「雪だるまのように、増えた分にもまた利益がつく」しくみを何と言うでしょう？

| 選択肢 | 考え方のポイント（feedback） |
|-|-|
| 単利 | 単利は、最初に預けたお金にだけ利益がつくしくみです。増えた分には利益がつきません。 |
| 複利 | 複利は、増えた分を引き出さずに置いておくことで、雪だるまのように育っていきます。 |
| 分散 | 分散は、お金をいろいろなところに分けることです。増え方のしくみとは別の言葉です。 |

<br>

## 3. 分散投資（slug: `diversification`）

- **ひとこと**：お金を、いろいろなところに分けること
- **やさしい説明**：1つの会社や1つの国だけにお金を集めず、いくつかに分けて投資することです。どこかが下がっても、ほかでカバーできるので、大きく減りにくくなります。
- **身近なたとえ**：卵をひとつのカゴに盛らない。カゴを落としても、卵を別々のカゴに分けておけば、全部は割れません。
- **ポイント**
  - 1つに集中させない
  - 損をしないわけではないが、大きく減りにくくなる
  - 会社、国、時期などで分けられる

### クイズ

**問題**：「卵をひとつのカゴに盛らない」は、どの考え方のたとえでしょう？

| 選択肢 | 考え方のポイント（feedback） |
|-|-|
| 分散投資 | 分散投資のたとえです。いくつかに分けておけば、どこかで失敗しても全部を失わずにすみます。 |
| 集中投資 | 集中投資は、1つにまとめて投資することです。卵をひとつのカゴに盛るほうですね。 |
| 長期投資 | 長期投資は、長い時間をかけて育てる考え方です。「分ける」ことのたとえではありません。 |

<br>

## 4. リスク（slug: `risk`）

- **ひとこと**：結果の「ふれはば」のこと
- **やさしい説明**：ふだんの「リスク」は「危険」という意味ですが、投資では「結果がどのくらい上下にぶれるか」という意味で使います。リスクが大きいほど、大きく増えることも、大きく減ることもあります。
- **身近なたとえ**：ジェットコースターと観覧車。ジェットコースターは上がり下がりが大きく、観覧車はゆっくりです。どちらも、乗る人の好みや体調に合わせて選びます。
- **ポイント**
  - 投資のリスクは「危険」ではなく「ふれはば」
  - リスクが大きいと、増えるときも減るときも大きい
  - 自分が落ち着いていられる大きさを選ぶ

### クイズ

**問題**：投資の世界で「リスクが大きい」とは、どういう意味でしょう？

| 選択肢 | 考え方のポイント（feedback） |
|-|-|
| 必ず損をする | ふだんの言葉ではそう感じますよね。でも投資では、損をする意味ではなく「結果のふれはば」のことです。 |
| 結果の上がり下がりが大きい | 投資の「リスク」は、このふれはばのことです。大きく増えることも、大きく減ることもあります。 |
| 危ないから、やめたほうがいい | リスクは「やめる理由」ではなく、「自分に合う大きさを選ぶ目安」として考えてみましょう。 |

<br>

## 5. 50歳からの投資（slug: `start-at-50`）

- **ひとこと**：50歳からでも、知って選ぶ価値がある
- **やさしい説明**：お金を使う時期は、仕事をやめたあとも長く続きます。預金だけでなく「お金を育てる」という選択肢を知っておくと、これからのお金を自分で考えやすくなります。始めるかどうかは、あなたが決めてよいことです。始めるなら、生活に使うお金を先に分けておきましょう。
- **身近なたとえ**：50歳から始める家庭菜園。若いころから始めた人と比べなくても、自分の庭の広さに合わせて育てれば、ちゃんと実りを楽しめます。
- **ポイント**
  - 50歳からでも、知っておく価値はある
  - 始めるかどうかは、自分で決めてよい
  - 始めるなら、生活のお金を分けて、無理のない金額から

### クイズ

**問題**：50歳から投資を始めるとき、まず大切にしたいことはどれでしょう？

| 選択肢 | 考え方のポイント（feedback） |
|-|-|
| 遅れを取り戻すため、大きな金額で始める | 焦る気持ちはよくわかります。でも、大きく減ったときに生活が苦しくならないかを、先に考えてみましょう。 |
| 生活に使うお金を分けてから、無理のない金額で始める | 大切な考え方です。生活のお金が守られていると、値下がりしても落ち着いていられます。 |
| もう遅いので、考えなくてよい | お金を使う時期は、これからも長く続きます。始めるかどうかは自由です。まずは「知っておく」だけでも、これからのお金を考える助けになります。 |
